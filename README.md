## 📌 Overview

Global License Manager is a modular desktop application designed to manage and monitor Windows license states through a structured graphical interface.

The application is built with a clean architecture approach, separating GUI components, core logic, and system-level utilities for maintainability and scalability.

It focuses on:

- Organized license state handling  
- Controlled system interaction  
- Professional desktop UI design  
- Structured logging and error handling

## 📦 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/vickydhale47/Global-License-Manager.git
cd Global-License-Manager
```

### 2️⃣ Create Virtual Environment

```bash
python -m venv venv
venv\Scripts\activate
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Application

```bash
python run.py
```

Or use:

```bash
run_gui.bat
```
